# 问题行为训练方案

每个方案 = **管理 → 需求 → 替代行为 → 渐进练习 → 何时转介**。日记里每天从中取 1–3 个小步骤。

---

## 玄关警戒吠叫 / 门铃狂叫（Grisha + Kikopup）
- 管理：窗户贴半透明膜、白噪音、婴儿门挡住玄关视线。
- 替代行为：门铃响 → 去垫子 / 跑来找主人拿零食（"门铃 = 去厨房找妈妈"）。
- 渐进：手机播放极低音量门铃 → 给零食 → 逐渐提高音量 → 真门铃 → 有人站在门外 → 开门。
- 主人：不要跟着吼（狗以为你也在叫），平静地说一声"谢谢，我知道了"后引导。

## 扑人 / 访客兴奋
- 管理：访客到来前牵引或在婴儿门后。
- 替代：四脚着地就奖励（零食丢在地上）；或教"叼玩具迎宾"。
- 访客配合：狗扑就转身无视，四脚着地再蹲下打招呼。
- Cesar 借鉴：主人先平静，进门前 5 分钟不和狗互动。

## 幼犬咬手 / 咬衣服
- 原因：探索、换牙、过度疲劳。先检查是否该睡觉了。
- 方案：咬手 → 手停住不动 → 递咀嚼玩具 → 玩具咬得好就继续玩；屡咬 → 平静中止游戏 30 秒。
- 不要：捏嘴、按倒、尖叫刺激（部分狗会更兴奋）。

## 暴冲 / 拉绳
- 工具：前扣胸背带、2m 牵引绳、腰包装零食。
- 方案：绳紧就停，绳松就走；在主人腿边的位置高频奖励（"奖励位置"）。
- 先在家里/走廊练，再到安静街道；散步分"训练段"和"自由嗅闻段"。

## 对狗/人/车的反应（狂吠、暴冲）——BAT
- 找到阈值距离：狗能吃零食、能嗅地。
- Mark & Move：看到刺激 → "Yes" → 掉头离开 → 奖励。
- 逐渐缩短距离（每次几步）。避开高峰时间散步。
- 有咬伤史或频繁爆发 → 转介行为兽医；可能需要药物辅助。

## 分离焦虑 / 独处问题
- 区分：无聊破坏 vs 真正恐慌（流涎、自伤、持续嚎叫、试图逃出）。
- 方案：从"主人起身 → 坐回"开始脱敏；离开信号（拿钥匙、穿鞋）去敏化；摄像头观察，**始终在狗不焦虑的时长内结束**。
- 恐慌型：尽早转介行为兽医，训练期间尽量不让狗独处超过其承受时长（托管、亲友）。

## 护食 / 资源守护
- 绝不：从狗嘴里抢、把手伸进碗里"证明你是老大"。
- 方案：路过食盆时往里加一块更好的食物（"人靠近 = 有好东西"）；教"交换"。
- 家中有儿童且已出现咆哮/咬 → 立即管理（分开喂食）+ 转介。

## 厕所训练
- 时机：睡醒、吃完、玩完、每 1–2 小时（幼犬月龄+1 ≈ 能憋的小时数）。
- 在正确地点排泄后 3 秒内奖励。失误不责骂，用酶清洁剂彻底清理。

## 召回
- 名字 / "来" 永远只代表好事；不在召回后做狗讨厌的事（洗澡、回家）。
- 游戏：两人对喊召回、躲猫猫、长牵引场地练习。
- "紧急召回"专用词 + 顶级奖励（如一整块鸡肉）。

## 害怕（怕声音、怕人、怕新事物）
- 让狗自己选择靠近或离开；对抗条件反射：刺激出现 = 好吃的。
- 雷声/烟花：提前准备安全窝、白噪音，严重者与兽医讨论抗焦虑方案。

## 老犬夜间不安 / 吠叫
- 先就医（疼痛、CCD）。夜灯、白天更多日晒与轻度活动、规律作息、嗅闻游戏。

---

## 转介信号（出现即建议专业帮助）
- 造成见血咬伤，或咬伤后不松口
- 对儿童有任何攻击迹象
- 自残、极度恐慌
- 行为突然改变（可能是医疗问题）
- 2–4 周正确执行方案仍无改善

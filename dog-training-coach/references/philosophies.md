# 训犬师理念整理

本 Skill 以"正向强化 + 主人的稳定状态 + 观察与理解犬"为主干。下表给出每位训犬师的**取（借鉴）**与**舍（不采用）**。

## 总览

| 训犬师 | 核心关键词 | 本 Skill 采用 | 本 Skill 不采用 / 谨慎 |
|---|---|---|---|
| **Emily Larlham（Kikopup）** | 正向强化、冷静奖励、自控力、幼犬社会化 | ✅ 主干方法论 | — |
| **Grisha Stewart（BAT）** | 让狗自己选择、距离管理、阈值下训练、恐惧/反应犬 | ✅ 主干方法论（反应性、怕生） | — |
| **MASUMI（Doggies 911）** | 观察犬、主人的姿态与心态、人犬关系 | ✅ 关系与主人态度部分 | 以官方一手资料为准，勿臆测其具体手法 |
| **Cesar Millan** | 平静而坚定的能量、清晰边界、控制兴奋、运动→规则→关爱 | ✅ 主人平静、边界、先消耗再训练 | ❌ 支配/阿尔法理论、身体压制、"泛滥法"式暴露 |
| **Tom Davis（No Bad Dogs）** | 实战干预、一致的规则、主人沟通 | ✅ 规则一致性、全家统一口令 | ❌ 矫正器具（P链等）作为常规手段 |
| **Larry Krohn** | 关系构建、真实生活场景训练、清晰传达信息 | ✅ 生活化训练（门口、散步、访客） | ❌ 电子项圈 |

## 1. Emily Larlham（Kikopup）——"冷静本身就是可以奖励的行为"

- **捕捉平静**（Capturing Calm）：狗自己趴下、安静时，安静地放一粒零食在它两爪之间。不叫醒、不兴奋。
- **奖励放置位置**很重要：想要它待在原地就把奖励送到原地；想要它离开就把零食丢远（"重置"）。
- **不给错误的机会**：用管理（围栏、牵引、婴儿门）防止问题行为被练习。
- **Default behaviors**：教狗"不知道做什么时，就坐下/看主人"。
- **主人的情绪也会传染**：训练时语速慢、声音低、动作轻。
- 擅长：幼犬咬手、扑人、兴奋控制、玄关礼仪、垫子训练（Mat training）。

## 2. Grisha Stewart（BAT：Behavior Adjustment Training）——"给狗选择权"

- **在阈值以下工作**：保持足够距离，让狗能"看到刺激但还能思考"（能吃零食、能嗅地、身体柔软）。
- **让狗主导探索**：用长牵引绳（3–5m）跟随狗，狗看完刺激自己转开时就是成功。
- **功能性奖励**：狗想要的往往是"离开/拉开距离"，那就把距离作为奖励。
- **Mark & Move**：狗注意到刺激 → 标记（"Yes"）→ 一起往回走 → 奖励。
- 擅长：怕生、怕狗、玄关警戒吠叫、散步中的反应性（暴冲、狂吠）。

## 3. MASUMI（Doggies 911）——"先读懂这只狗，再看自己的状态"

- 重点在**观察犬的状态**与**主人的姿态/心态**，把问题放在"人犬关系"里理解。
- 本 Skill 在每篇日记中设置「🤝 关系小课堂」，用于呼应这一理念。
- 注意：MASUMI 的具体方法请以 Doggies 911 官网与官方 YouTube 为一手资料，教练不应虚构其主张；可以建议主人对照观看。

## 4. Cesar Millan——"主人平静，狗才平静"

- 可借鉴：
  - **Calm-assertive**：主人情绪稳定、动作果断但不粗暴。
  - **运动 → 规则 → 关爱** 的顺序：先满足运动与嗅闻需求，再练规则，最后给关注。
  - **清晰的边界**：门口、餐桌、沙发等有一致的规则。
- 不采用：
  - "狗想当头狼，你要统治它"——现代行为学认为家犬与人之间不存在这种地位争夺，多数问题源于恐惧、挫败或未学会。
  - 压制、戳脖子、强行翻身。
  - 让狗"硬扛"刺激直到不动（常是习得性无助而非放松）。

## 5. Tom Davis（No Bad Dogs）——"规则要一致"

- 可借鉴：全家统一口令与规则、问题行为要在真实场景中处理、主人要学会"给明确的信息"。
- 不采用：以P链/矫正项圈作为常规工具。替代：Y型胸背带 + 前扣防暴冲、正向的松绳随行训练。

## 6. Larry Krohn——"在真实生活里训练"

- 可借鉴：门铃、访客、散步、咖啡店等**真实情境**的分阶段练习；强调先建立关系和沟通。
- 不采用：电子项圈。替代：远距离召回用长牵引 + 高价值奖励 + 召回游戏。

## 统一方法论（教练用）

1. **管理**：先阻止问题被反复练习
2. **满足需求**：运动、嗅闻、咀嚼、睡眠（成犬 12–14h，幼犬/老犬 18–20h）
3. **教替代行为**：告诉狗"应该做什么"，而不只是"不准"
4. **强化**：奖励时机 ≤ 1 秒，可用响片或标记词（"Yes!"/"好！"）
5. **3D 渐进**：距离 Distance、时长 Duration、干扰 Distraction，一次只升一个
6. **主人状态**：深呼吸、慢动作、低声，像 Cesar/MASUMI 强调的那样先稳住自己

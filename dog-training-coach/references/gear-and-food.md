# 道具与食品清单

列清单时格式：**名称 · 用途 · 选购要点 · 推荐成分/材质 · 避开**。不编造品牌成分表；提及品牌时提醒"以包装标签为准"。

## 一、训练道具

### 基础（所有阶段）
| 道具 | 用途 | 选购要点 |
|---|---|---|
| Y型胸背带（可带前扣） | 散步、防暴冲 | 不压迫喉咙与肩关节；Y型前胸；能塞进两指 |
| 牵引绳 1.5–2m | 日常散步 | 尼龙/生物胶（BioThane），不选伸缩绳（无法教松绳） |
| 长牵引绳 5–10m | 召回、BAT | BioThane 不吸水易清洁；**仅接胸背带** |
| 零食袋/腰包 | 及时奖励 | 磁吸开口、单手可取 |
| 响片（可选） | 精准标记 | 声音太大的可换柔音款，或用标记词 |
| 垫子/放松垫 | 垫子训练、"去你的位置" | 防滑底、可机洗 |
| 婴儿门 / 围栏 | 管理 | 狗无法跳过的高度 |
| 狗笼（航空箱/软笼） | 安全窝、乘车 | 能站起、转身、躺平即可 |

### 丰富化与脑力
| 道具 | 用途 | 要点 |
|---|---|---|
| 嗅闻垫 | 放慢进食、消耗精力 | 布条牢固、可水洗 |
| 漏食玩具（可冷冻填充） | 独处、换牙、解压 | 天然橡胶，尺寸大于狗喉咙 |
| 舔食垫 | 合作护理、洗澡剪指甲时分散 | 食品级硅胶 |
| 益智玩具 | 脑力训练 | 从初级开始，防挫败 |
| 拔河绳 | 有规则的游戏 | 教"放下" |

### 幼犬专用
- 磨牙玩具（软橡胶，可冷冻）、厕所垫/尿垫、酶清洁剂（分解尿液气味的生物酶类，避免含氨清洁剂——氨味类似尿味）

### 老犬专用
- 防滑垫/地毯、宠物斜坡/台阶、记忆棉/骨科床垫、夜灯、软质零食、支撑式胸背带（带提手）

### ❌ 本 Skill 不推荐（遇询问时解释替代）
电击项圈、P链/尖刺项圈、窒息链、止吠喷雾/电击止吠器、伸缩牵引绳（训练期）

## 二、训练零食

### 奖励价值分级
| 等级 | 例子 | 何时用 |
|---|---|---|
| 低 | 日常狗粮颗粒 | 家里、简单复习 |
| 中 | 商品训练零食、冻干颗粒 | 一般训练 |
| 高 | 自煮无调味鸡胸肉、冻干肝、奶酪少量 | 户外、干扰大、反应性训练、召回 |
| 顶级 | 鸡肉块、肉泥挤管 | 紧急召回、可怕刺激 |

### 选购成分要点
- ✅ **推荐**：单一或少量成分（如"鸡胸肉 100%"）、第一成分为明确肉类（鸡肉、牛肉、鳕鱼、三文鱼）、冻干或低温烘干
- ✅ 尺寸：豌豆粒大小（小型犬可更小），软、好嚼，1–2 秒吃完
- ⚠️ **避开**：木糖醇（Xylitol，极毒）、人工色素（如诱惑红、柠檬黄）、BHA/BHT/乙氧基喹啉类人工防腐剂、过多糖/盐/甘油、来源不明的"肉类副产品"、丙二醇
- 过敏犬：选单一新蛋白（鹿肉、鸭肉、马肉、袋鼠肉）或水解蛋白，以兽医建议为准
- **热量**：零食 ≤ 每日总热量 10%；训练多的日子减少正餐

### 自制零食（最可控）
- 水煮鸡胸肉切丁（无盐无油）、烤红薯丁、水煮蛋白、少量南瓜泥（纯南瓜，非派馅）
- 蔬果可选：胡萝卜、苹果（去籽和核）、蓝莓、黄瓜

## 三、按阶段的主食选购要点

| 阶段 | 关注点 |
|---|---|
| 幼犬 | 标注"幼犬/全生命阶段"且符合 AAFCO 或 FEDIAF 营养标准；大型犬选大型犬幼犬粮（控制钙磷） |
| 成犬 | 明确动物蛋白为第一成分；按体况评分（BCS）调整喂量 |
| 老犬 | 易消化蛋白、适当控制热量、Omega-3（EPA/DHA，鱼油）、关节成分（葡萄糖胺、软骨素、绿唇贻贝）——补充剂先问兽医 |
| 短吻/易胖犬 | 低热量、高纤维、颗粒形状易咀嚼 |

换粮：7–10 天渐进混合（25% → 50% → 75% → 100%）。

## 四、⚠️ 有毒/危险食物（每份采购清单都要提醒）
木糖醇（口香糖、部分花生酱）、巧克力/可可、葡萄/葡萄干、洋葱/大蒜/葱/韭菜类、夏威夷果（澳洲坚果）、酒精、咖啡因、生面团、熟骨头（易碎刺伤）、牛油果、过咸食物、玉米棒芯（肠梗阻）

误食 → 立即联系兽医或动物急救热线，不要自行催吐。
